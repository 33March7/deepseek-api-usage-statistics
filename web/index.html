手动填写登录凭证

1. 在浏览器中打开 platform.deepseek.com 并登录
2. 按 F12 打开开发者工具 → 控制台(Console)
3. 输入 JSON.parse(localStorage.userToken).value 并回车
4. 把输出的内容(很长的一串字符)复制粘贴到下方
